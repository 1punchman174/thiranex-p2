# Customer Segmentation Project

## Overview

This project performs customer segmentation using K-Means Clustering based on customer income and spending behavior.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Features

* Data preprocessing
* Elbow Method
* K-Means clustering
* Customer visualization
* Segment analysis

## Dataset

Mall Customers Dataset

## Outcome

Customers are grouped into different clusters based on spending patterns and annual income.
